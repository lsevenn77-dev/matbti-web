# 캐릭터 3D 모델 (GLB)

`manifest.json` 에 `캐릭터ID: 경로` 를 적으면 해당 캐릭터를 코드 캐릭터 대신 GLB 로 표시한다.
파일이 없거나 불러오기 실패하면 코드 캐릭터로 자동 대체된다.

| ID | 가명 | 상태 |
|---|---|---|
| c01 | 태양 | Higgsfield Meshy 7 시험 생성 (job ef0d2cab-f9b5-429a-a6db-7022527899e9). 파일은 직접 받아서 `c01.glb` 로 저장 |
| c02~c12 | 우주~여름 | 미생성 |

생성 설정: 정면 A-포즈 원본 이미지(GPT Image 2.6) → meshy_v7_image_to_3d, 15,000 폴리곤, 텍스처, 리깅.
